# PHASE 12R — PRODUCTIVITY, ACCOUNTABILITY & DOCUMENTS

**Backend:** seluruh lingkup `legacy/roadmap/PHASE-12-PRODUCTIVITY-AND-DOCUMENTS.md`: Bagian A (task/Kanban model, pengingat & jadwal belajar, **mode ketegasan Santai/Biasa/Strict**, penggunaan layar opt-in) dan Bagian B (Document Service dengan worker terisolasi, tool open source, **standar kualitas dokumen B3**, discovery "Artcraft", verifikasi render, pengujian). Semua aturan privasi/opt-in/"menagih bukan mengunci" tetap.

## UI

| Fitur | Permukaan Bloom |
|---|---|
| Capture tugas lewat chat ("saya punya tugas X deadline Jumat") (UR-09) | Panel Assistant → Core membuat task; konfirmasi ringkas |
| Hari ini / berikutnya / tambah cepat | **Panel Tasks** Island, **terintegrasi Pomodoro + Kalender Bloom** |
| Kanban penuh, proyek, kalender, tenggat, dependensi | **Workspace → Kanban** (kolom dapat diatur, drag-drop, filter) |
| Jadwal belajar | Workspace + bubble "mulai blok belajar" (timer fokus Bloom) |
| Mode ketegasan (UR-10) — UI **dan** chat | Tab Produktivitas di Settings + perintah lewat Assistant |
| Check-in saat laptop dibuka (Strict) | Island membuka panel Tasks otomatis; eskalasi bertahap; **overlay hanya eskalasi terakhir** (berkas 07 §6); "Tunda" dengan alasan |
| Nudge penggunaan layar (UR-11, laptop) | Bubble nudge; data lokal; halaman transparansi + hapus semua di Settings |
| Pembuatan dokumen/konversi/kompres/merge/OCR (UR-06, 07, 14, 15) | **Bubble progres** + hasil "Buka"; antrean dan templat di **Workspace → Documents** |

Catatan "Artcraft": lakukan discovery sesuai legacy 12 §B4; bila ambigu → OD (bukan penghalang).
Verifikasi: waktu disimulasikan untuk uji pengingat/mode; privasi (data tak terkirim saat opt-out); dokumen **dibuka dan diverifikasi** (render); visual + resource; **VC-06** (Tasks + nudge Strict + Kanban) dan **VC-07** (Documents).
