# OWNER VISUAL CHECK — VC-01

### VC-01 — Irisan Vertikal Stage H2 (Dynamic Island Indicator, Assistant Panel, Approval Bubble & Settings)

- **Apa yang dilihat:** Dynamic Island Hime bermorfosis mulus menggunakan spring physics Bloom tanpa window chrome desktop. Menampilkan status Hime Core di status pill, panel Assistant terintegrasi saat di-klik/swipe, live activity bubble di samping Island saat ada approval pending, kartu detail approval untuk setuju/tolak aksi sensitif, serta tab Hime di Settings Bloom.
- **Cara menjalankan (owner):**
  Jalankan perintah berikut di PowerShell (aman, dibatasi waktu 60 detik, taskbar otomatis pulih saat selesai):
  ```powershell
  Set-Location -Path "X:\folder_ai\Hime-Bloom"
  powershell -ExecutionPolicy Bypass -File scripts\dev-hime.ps1 -Seconds 60 -ExePath "src-tauri\target\debug\bloom.exe"
  ```
  *Langkah interaksi saat berjalan:*
  1. Perhatikan Dynamic Island di bagian atas layar: titik status hijau/abu-abu Hime berada di sebelah jam pill.
  2. Klik pada pill notch atau geser panel untuk membuka panel **Hime Assistant** (ukuran 380×300, frameless). Tampilan secara jujur menyatakan *"AI belum terhubung — Menunggu Fase 08R"* dan input dinonaktifkan.
  3. Buka Settings (via klik kanan tray icon Hime atau `Ctrl+,`): tab **Hime** menampilkan status IPC Pipe `\\.\pipe\hime-ipc`, tombol Ping Core, dan simulator pemicu approval.
  4. Klik tombol simulasi approval di tab Settings: sebuah **Approval Bubble** berwarna amber (`.activity-bubble`) muncul di sebelah kanan Island dengan hitungan mundur detik. Klik bubble tersebut untuk melihat Island bermorfosis membuka kartu **Approval Detail** (380×160) dengan tombol **Setujui** dan **Tolak**.
- **Screenshot terlampir:**
  - Runtime environment bot berjalan di headless Session 0 tanpa handle display GDI (`CopyFromScreen` mengembalikan error Windows handle invalid). Sesuai aturan Master Prompt berkas 04 §5 & §6.3, status tangkapan layar otomatis ditandai `[NOT TESTED — MEMERLUKAN VERIFIKASI MONITOR LANGSUNG OLEH OWNER]`.
